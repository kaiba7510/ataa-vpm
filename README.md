# Avatar Texture Auto Adjuster（体験版）VPM リスティング

VRChat Creator Companion（VCC）で **Avatar Texture Auto Adjuster の体験版** を入れるためのリスティングです。

## 入れ方

1. VCC の **Settings → Packages → Add Repository** を開く
2. 次の URL を入れて **Add** を押す

   ```
   https://kaiba7510.github.io/ataa-vpm/index.json
   ```

3. プロジェクトの **Manage Project** で「Avatar Texture Auto Adjuster（体験版）」を追加する

製品版は BOOTH の購入者向けに別の URL で配っています。製品版を入れると体験版は自動で外れます。

このリポジトリには配布用の zip とリスティングだけを置いています（ツールのソースはありません）。
