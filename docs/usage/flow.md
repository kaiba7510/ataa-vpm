# 画面の見方と基本の流れ

![ATAA ウィンドウ](/img/02_ataa_whole.png){.shot}

## 画面の見方

Unity 上部メニューの **Cigarless > ATAA** から開きます。

- **上部ヘッダー**:
  - 左側: ツール名・エディション（`Pro` / `Trial`）、準備状態ピル（**準備完了** / **あと N ステップ ›** — 押すと次に設定が必要なカードへ移動）、選択中の対象アバター名。
  - 右側: **Sceneで顔を映す**（Scene ビューのカメラを対象アバターの顔正面へ移動）、**FaceMap エディター**、**更新**（FaceMaps フォルダとシーン内のアバターを再読み込み）。
- **左：アバター管理**: 対象アバターの選択、自動認識サマリー、必要に応じた手動変更（顔メッシュ・アバター基準・顔テクスチャ）。
- **中央：プレビュー**: **3Dビュー** と **2D UV** の表示切り替え、表示オプション、ライブプレビュー、メイク前後の比較ボタン。
- **右：フィッティング調整**: ステップ進捗（`ステップ 0 / 6`）、**メイク元**、**調整するパーツ**、**位置・大きさ**、**目の詳細調整**、**口の調整**、**仕上げ**、下部実行バー（適用状態・**メイク適用**・**適用を解除**）。
- **下部ステータスバー**: 処理の結果や注意を 1 行で表示します（マウスを乗せると全文が見られます）。右端は処理状態（`Ready` / `Rendering...` / `Applying...`）です。

ボタンや設定項目の多くには、マウスを乗せると詳しい説明（ツールチップ）が表示されます。迷ったときはカーソルを合わせて確認してください。

## 基本の流れ

ATAA では、アバターごとに「目・鼻・口・頬がテクスチャのどこにあるか」を記録した基準データ（**FaceMap**、画面では「アバター基準」「メイク基準」）を使います。メイクを作った側のアバター（**メイク元**）と、メイクを乗せたいアバター（**対象**）の両方に FaceMap が必要です。

1. **対象アバターを選ぶ**（[→](/usage/avatar)）: 左の **アバター管理** でシーン上のアバターを選ぶと、顔メッシュ・アバター基準・顔テクスチャが自動で認識されます。
2. **メイク元を選ぶ**（[→](/usage/makeup)）: 右の **メイク元** でメイクテクスチャとメイク基準を選びます。
3. **プレビューで確認する**（[→](/usage/preview)）: 中央の **3Dビュー** や **2D UV** で仕上がりを確認します。
4. **必要なら微調整する**（[→](/usage/fitting)）: ズレや濃さ・肌色・目や口の形を合わせます。
5. **メイクを適用する**（[→](/usage/apply)）: 右下の **メイク適用** を押して、合成テクスチャとマテリアルを書き出します（製品版）。

作成した FaceMap は `Assets/Cigarless/ATAA_Data/FaceMaps/` に保存され、組み合わせごとの微調整は `Assets/Cigarless/ATAA_Data/FaceMaps/Adjustments/` に自動保存されます。次回同じアバターや組み合わせを開いたときは自動で読み込まれます。メイク適用で書き出したファイル（`Generated/`）や、プロジェクトの外から読み込んだメイク画像（`Assets/Cigarless/ATAA_Data/Makeups/`）も、すべて `Assets/Cigarless/ATAA_Data/` の中に入ります。ツールを入れ直すときはこのフォルダを消さないでください（1.3.5 までの `Assets/ATAA_Data/` は、開いたときに自動でここへ移ります）。
