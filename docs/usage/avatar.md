# 対象アバターを準備する

![アバター管理](/img/03_avatar_panel.png){.shot}

上から順に状態が揃います。各カードの丸印の色で進み具合が分かります（緑: 完了 / 青点滅: 次に操作が必要 / 橙: 要確認 / 灰: 待機）。

1. **アバター**:
   - メイクを乗せたいアバターを、シーンからドラッグ＆ドロップするか一覧から選びます。
   - 見つからないときは **更新** を押してください。プロジェクト内のプレハブは適用対象にできません（必ずシーン上に置いたアバターを選んでください）。
   - シーン内でアクティブなアバターが 1 体だけのときは、最初に自動で選ばれます。
   - 一覧の左の丸印は解析状態を表します（緑: 準備 OK / 橙: 要確認 / 灰: 未解析）。
2. **自動認識サマリー**:
   - アバターを選ぶと、顔メッシュ・アバター基準（一時生成）・顔テクスチャを自動で認識します。
   - 問題がなければコンパクトなサマリーカードだけが表示されます。内容を変えたいときは **おかしい場合は手動変更 ▾** を押して詳細カードを開きます（不足や要確認があるときは自動で開きます）。
3. **顔メッシュ**:
   - 顔の `SkinnedMeshRenderer` を選びます（通常は自動で選ばれます）。
   - 候補の行にマウスを乗せている間は、中央の **3Dビュー** にそのメッシュだけを単独表示して確かめられます。
4. **アバター基準**:
   - 登録済みの FaceMap を一覧から選ぶか、**アバター基準を自動生成**（または **自動生成し直す（上書き確認あり）**）を押します。
   - 顔メッシュのまばたき・口のブレンドシェイプの動きから、目・鼻・口・頬の位置と目の線を推定します。
   - 「要確認」が出たときや目の線を直したいときは、**FaceMap エディターで微調整** を押して位置を確かめてください。
5. **顔テクスチャ**:
   - **候補から選ぶ ›** から、顔マテリアルが使っているテクスチャをサムネイルを見て選びます（サムネイル欄へのドラッグ＆ドロップもできます）。
