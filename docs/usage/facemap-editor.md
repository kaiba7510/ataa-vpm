# FaceMap エディター

![FaceMap エディター](/img/05_facemap_whole.png){.shot}

FaceMap を新規作成したり、自動生成された位置・目の線・輪郭・口の線を詳しく確認・修正したりするウィンドウです。ATAA ウィンドウ上部の **FaceMap エディター**、左ペインの **FaceMap エディターで微調整**、または注意メッセージ横のボタンから開きます。

### ツールバー

- **＋ 新規作成**: 新しい FaceMap を作ります。
- **読込**: `Assets/Cigarless/ATAA_Data/FaceMaps/` 内の保存済み FaceMap を開きます（体験版では一時保存一覧またはファイルを選択）。
- **⚡ 自動生成**: 右の「アバターから自動作成」で指定したアバターからパーツと目の線を配置します。指定がない場合は標準テンプレートの位置へ仮配置することもできます。
- **3D ビュー**: 中央にアバターの 3D 顔ビューを表示し、目の線（黄）・目の下の線（緑）が実際の顔のどこに当たるかを重ねて確認できます。
- **上書き保存**（体験版: **一時保存**） / **別名保存**（体験版: **別名で一時保存**）: FaceMap を保存します。**保存するまで ATAA ウィンドウ側には反映されません。**
- 右端には現在開いているファイル名と、必須パーツの配置数（`必須 0 / 6`）が表示されます。

### テクスチャの読み込みとビュー操作

- **テクスチャ読み込み**: 左の領域へ Project ビューまたは PC から顔テクスチャをドラッグ＆ドロップするか、**＋ テクスチャを選択** から選びます（このテクスチャは編集中のガイド表示および肌色参照の記録に使われます）。
- **ビュー操作**:
  - 左クリック: パーツの配置・選択・枠の移動
  - 四隅・辺の中点のドラッグ: 枠のサイズ変更（`Shift` キーを押しながら四隅をドラッグすると中心を固定して拡大縮小）
  - 中ドラッグ / 右ドラッグ: 表示の移動（パン）
  - ホイール: ズーム / 中ダブルクリックまたは **⤢ 全体表示**: 100% 全体表示
  - `Ctrl+Z` / `Ctrl+Y`: 元に戻す / やり直し
  - `Alt` ＋移動操作: 左右対称が ON でも片側だけ動かす
  - **対称軸表示**: 左右対称の中心線とハンドルをテクスチャ上に表示します（表示設定のみ）。

### 右パネル（顔パレット・パーツ編集）

![顔パレット](/img/07_facemap_palette.png){.shot}

- **顔パレット**: 配置するパーツを選びます。
  - 必須パーツ（6 個）: 右目・左目・鼻・口・右頬・左頬
  - 任意パーツ: 顎
  - **左右対称: ON / OFF**: ON のときは目・頬の片方を置くと反対側にも配置され、移動すると相方も反転して動きます。非対称メイクを作るときは OFF にします。
  - 自動作成で不確かな領域（橙枠・**要確認**）が出たときは、**次へ** を押して順に確認してください（位置や大きさを動かすと確認済みになります）。
- **選択中パーツの微調整**: **置き直し**、**削除**、**位置の微調整**（十字パッド＋**移動量**）、**横幅**・**高さ**、**左右の間隔**（目・頬）、**中心線に合わせる**（鼻・口・顎）、**詳細設定（数値）**（u, v, 幅, 高さ）。
- **目の設定**（目を選択中）:
  - **目の開いていない素体**: 白目・瞳がテクスチャに描かれておらず、目の部分がメッシュの穴になっている素体のときに ON にします。この素体のメイクを目の開いた素体へ写すときは、目の開いた部分に元の目が残ります。
  - **目の線（上まつげの生え際）**: まぶたと目の境界線。3D ビューで上まつげの生え際に合わせてください。
  - **目の下の線（下まつげの生え際）**: 目の開いた部分の下の縁。3D ビューで下まつげ・下まぶたの境界に合わせると、下まつ毛や涙袋のずれを防げます。
  - **目の輪郭（縁に沿って写す）**: ON にすると目の開いた部分の縁をなぞる水色の点が出ます（目の線・目の下の線から初期形状を生成）。メイク元・対象の両方にあると、丸い目と切れ長の目のように形が違っても、目を囲むラインや目尻の跳ね上げ・下まつげを縁に沿って写せます。
- **口の設定**（口を選択中）:
  - **口の線（唇の合わせ目）**: 上唇と下唇の合わせ目の高さ。メイク元・対象の両方にあると、上唇と下唇を別々に合わせて写せ、「中央の折れ（v / ^）」も使えるようになります。

### 下部の折りたたみ設定

- **左右対称の軸**: 中心 u の入力・移動、**鼻に合わせる**、**ミラーで揃える**、**反転して重ねる**（左右反転したテクスチャを重ねて中心線を確認）。
- **アバターから自動作成**: アバター・顔のレンダラー・**まばたき**・**口** のブレンドシェイプ、**スタイル**（自動／標準アニメ／デフォルメ／ちび）、**自動判定の強さ**（右で領域広め／左で狭め／0 が既定）を指定して **自動作成** を実行します。
- **メイク基準の情報・表示**: 名前、対応アバター、対応アバター名、ファイル名、ポインタのサイズ（テクスチャ上の点・ハンドルの表示倍率）を設定します。
- 一番下の **✓ 保存して完了**（体験版: **✓ 一時保存して完了**）で保存します。
