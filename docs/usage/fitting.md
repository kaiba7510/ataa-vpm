# フィッティングを微調整する

![フィッティング調整](/img/10_fitting_panel.png){.shot}

微調整の結果は組み合わせごとに自動保存され、元の FaceMap（アバター基準・メイク基準）自体は変わりません。

### 調整するパーツ

- 上部のタブから **全体** または個別のパーツ（目・鼻・口・頬・顎など）を選びます。調整したタブには `★` が付きます。
- 個別パーツを選んでいるときは **合成する** チェックボックスで、そのパーツにメイクを乗せるか（ON / OFF）を切り替えられます（OFF にすると元のアバターのパーツを残します）。
- 見出しの **調整をすべてリセット** を押すと、この組み合わせの位置・大きさ・目や口の調整・合成範囲をすべて自動の状態に戻せます（メイクの濃さは変わりません）。

### 位置・大きさ

- **十字パッド（▲▼◀▶ +）**: クリックで 1 ステップ、押したままドラッグすると連続して移動します。中央の `+` はドラッグで上下左右に動かせます。
- **移動量**: `0.001` / `0.005` / `0.01` / `0.05` から 1 ステップの大きさを選びます。
- **横幅 / 高さ / 回転**: `-` `+` ボタン（クリックまたは左右ドラッグ）で調整します。
- **パーツのまわりだけ動かす (全パーツ共通)**: ON にすると各パーツの周辺だけを局所的に動かし、**回転** も使えるようになります。
- **左右の間隔**（目・頬の選択時）: **→← 縮小** / **←→ 拡大** で左右パーツの間隔を調整します。
- **左右位置: 中心線に合わせる**（鼻・口・顎の選択時）: アバターの中心線へ横位置を揃えます。
- **詳細 (数値入力)**: 折りたたみを展開すると `位置のずれ`・`拡大縮小`・`回転 (°)`・`間隔の変化` を数値で直接入力できます。
- 見出しの **自動に戻す** で、現在選んでいるタブ（全体または選択中パーツ）の位置・大きさ・回転・間隔だけを初期値に戻せます。

### 目の詳細調整（`目` タブ選択時）

- **下まつ毛幅**: 下まつ毛側の帯の幅を伸縮します。
- **目尻フレア**: 目尻側を広げて馴染ませます。
  - ※ **下まつ毛幅**・**目尻フレア** は、メイク元と対象の両方の FaceMap に「目の下の線」があるときに使えます。
- **アイライン高 / 下まぶた線**: 対象アバターの目の線・目の下の線の高さを組み合わせごとに微調整できます（2D UV 上の目の枠の左右つまみでも操作できます）。
- 見出しの **自動に戻す** で目の詳細調整を初期値に戻します。

### 口の調整（`口` タブ選択時）

- **口角の上下（弧）**: 口の両端（口角）を上下して唇全体をゆるい弧に曲げます（`-100%` 下がる ⌒ 〜 `+100%` 上がる ‿、中央は動きません）。
- **中央の折れ（v / ^）**: 唇の合わせ目の中央だけを上下して v / ^ に折ります（`-100%` 下げる v 〜 `+100%` 上げる ^。メイク元と対象の両方の FaceMap に「口の線」があるときだけ使えます）。
- 各スライダー右の `↺` で個別に 0% へ戻せます。見出しの **自動に戻す** で口の調整を両方とも 0% に戻せます。

### 仕上げ

- **メイクの濃さ**: メイクの不透明度（`0.00` 〜 `1.00`）を調整します。
- **肌色を合わせる**: メイク元の素体の肌色と対象の肌色の比に合わせて、メイク色味を自動補正します。
  - チェックを ON にしてプレビューが作られると、直下に合わせた比（例: `対象の肌色に合わせています（R×... G×... B×...）`）または合わせていない理由が表示されます。
  - 肌の部分が透明な「重ねるだけ」のメイクを使う場合、メイク元 FaceMap に記録された顔テクスチャから素体の肌色を測ります。メイク元 FaceMap の顔テクスチャが「メイクだけの透過画像」のまま保存されていると素体の肌色が分からないため、メイク元の素体の顔テクスチャを FaceMap エディターで開いてメイク元 FaceMap を保存し直してください。
- **合成範囲**: 折りたたみを展開して **広げ量**・**ぼかし**・**OFF の境界のぼかし** を調整できます。
- 見出しの **自動に戻す** で仕上げ項目を既定値に戻します（位置・目・口の調整は変わりません）。
