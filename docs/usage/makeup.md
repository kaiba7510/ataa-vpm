# メイク元を選ぶ

![メイク元](/img/08_makeup_source.png){.shot}

右パネル上部の **メイク元** カードで設定します。

### メイクテクスチャ（上段）

- **ドラッグ＆ドロップ**: Project ビューの `Texture2D` または PC 上の画像ファイル（PNG / PSD 等）をカードへ直接ドロップします。
- **ファイルから選択...**: ファイル選択ダイアログから画像を選びます。プロジェクト外の画像も自動でインポートされます（体験版ではファイル保存せずメモリ上に読み込みます）。
- **候補から選ぶ ›**: 選択中メイク基準の顔テクスチャ・シーン内他アバターの顔テクスチャ・最近使ったメイクの履歴から選べます。
- 顔全体のテクスチャでも、メイク部分だけの透過画像でも使えます。
- テクスチャを選んだとき、シーン内の他アバターが使っているテクスチャや過去に使った履歴と一致すれば、対応するメイク基準も自動で選ばれます。

### メイク基準（下段）

- ドロップダウンから、メイクを作ったアバターの FaceMap（またはまだ FaceMap がないシーン内アバター）を選びます。
- メイク元のアバター（シーン上のアバターまたは Project ビューのプレハブ）を「メイク基準」の行へ直接ドラッグ＆ドロップして、FaceMap を自動作成することもできます。

### 基準が一覧にない場合

メイク基準が未選択のとき（または右上の **作成 / 微調整 ▾** から開いたとき）は、作成ボックスから作れます。

- **元アバターから自動作成**: 元アバター（シーン上または Project のプレハブ）を指定して自動作成します。プレハブを指定した場合もシーンを汚さず一時解析して作成します。
- **画像から手動作成**: いま選んでいるメイクテクスチャを引き継いで **FaceMap エディター** を開きます。エディターで保存すると自動でメイン画面へ反映されます。

すでにメイク基準を選んだあとでも、右上の **作成 / 微調整 ▾** から「選択中のメイク基準を微調整（FaceMap エディター）」「元アバターから自動作成...」「メイクテクスチャをクリア」などを実行できます。
