# プレビューで確認する

![プレビューのツールバー](/img/09_preview_toolbar.png){.shot}

対象アバターとメイク元の両方が揃うと、中央のプレビューに仕上がりが出ます。

### 上部ツールバーと表示切り替え

- **3Dビュー / 2D UV**: 顔の立体で確かめるか、テクスチャ平面で確かめるかを切り替えます。
- **3Dビュー の表示ボタン**:
  - **装飾品: 表示 / 非表示**（`H` キー）: 前髪やメガネなどの装飾メッシュを一時的に隠して、顔だけを見やすくします。
  - **補助ライト: ON / OFF**: カメラに追従するライトを当て、暗い環境でも色味や境界を見やすくします。
  - **背景**: 押すたびに `暗い` → `中間` → `明るい` → `チェッカー` で切り替わります。どれも無彩色のグレーなので、肌色の見え方に色偏りが出ません。
  - **正面リセット**: カメラを顔の正面・既定の距離へ戻します。
- **2D UV の表示ボタン**:
  - **結果 / メイク前 / メイク元 / マスク**: 表示する画像を切り替えます（「マスク」はメイクが合成される範囲を確認できます）。
  - **全体表示**: 拡大・移動した表示を全体に戻します。
- **調整を表示: ON / OFF**: ON の間、調整中の結果をシーン上のアバターにも一時的に反映します（アセットは書き換わりません）。ウィンドウを閉じる・Play モードに入る・スクリプト再コンパイル時には自動で元の見た目に戻ります。

### 比較と操作

- **押している間: メイク前**（`C` キー）: 押している間だけ、適用前（メイク前）の顔を表示します。適用済みの状態からでも、元の顔と見比べられます。
- **押している間: 高画質 (2048)**（体験版のみ）: 押している間だけ 2048px（透かし入り）で細部を確認できます。
- **3Dビューの操作**: 右ドラッグで回転、中ドラッグで平行移動、ホイールでズーム。
- **2D UV の操作**: 中ドラッグで平行移動、ホイールでズーム。表示されているパーツの枠をドラッグして移動、四隅をドラッグして拡大縮小（`Shift` キーで縦横比固定）できます。目の枠の左右のつまみでは、アイライン高・下まぶた線も直接動かせます。
