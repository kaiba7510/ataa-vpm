# メイクを適用する・元に戻す

::: info 製品版の機能です
体験版ではメイク適用ボタンは押せません。
:::

![メイク適用](/img/12_apply.png){.shot}

右下の実行バーに現在の適用状態が表示されます（`未適用 (プレビューモード)` / `メイク適用済み` / `適用済み・調整の変更は未反映`）。

1. 準備が揃ったら、右下の **メイク適用** を押します。
2. 合成したテクスチャと複製マテリアルが `Assets/Cigarless/ATAA_Data/FaceMaps/Generated/<アバター>/<メイク>/` に生成され、シーン上の対象アバターの顔マテリアルに適用されます。
   - **元のテクスチャと元のマテリアルは一切書き換えません。**
   - 適用済みになると、ステータス欄の **場所を表示** から生成されたテクスチャを Project ビューで選択できます。
3. 元に戻したいときは **適用を解除** を押します（Unity の Undo `Ctrl+Z` でも戻せます）。**適用を解除** を押すと、マテリアルを元に戻したうえで「調整を表示」も自動で OFF になり、元の見た目に戻ります。
4. 未適用の調整がある状態でウィンドウを閉じる、または別のアバターへ切り替えるときは、確認ダイアログが表示されます（「適用して進む / 適用せず進む / キャンセル」）。

### 他ツールとの併用

- **NDMF / Modular Avatar**: 非破壊プレビューと共存できます。
- **TexTransTool / lilToon デカール等**: ATAA で合成したテクスチャ・マテリアルの上から、色改変やほくろ・シール等を重ねる運用もそのまま行えます。
