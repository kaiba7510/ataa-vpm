# 困ったとき（FAQ）

- **アバターが一覧に出ない / 選べない**: シーンに配置されているか確認し、右上または左パネルの **更新** を押してください。Project ビューにあるプレハブは対象アバターには選べません（メイク元の基準自動作成には使えます）。
- **アバター基準を自動生成できない**: まばたきのブレンドシェイプが自動検出できない場合です。**FaceMap エディター** の **アバターから自動作成** を開き、**まばたき** と **口** のブレンドシェイプを手動で選んで **自動作成** を押してください。
- **枠の位置や目の線が大きくずれる**: FaceMap エディターの **アバターから自動作成** で **スタイル**（標準アニメ／デフォルメ／ちび）を選び直すか、**自動判定の強さ** を変えて作り直したあと、テクスチャビューや 3D ビューを見ながら微調整してください。
- **メイクが浮いて見える / 肌色を合わせるが効かない**: **仕上げ** の **肌色を合わせる** を ON にしてください。透過メイクを使用していて「肌色を合わせていません」と出ている場合は、メイク元 FaceMap に素体の顔テクスチャを開いた状態で保存し直すと素体肌色を測定できるようになります。
- **口元が崩れる**: [画面に出る注意・メッセージの意味](/support/messages) の「口の大きさがメイク元と大きく違います」が出ている場合は、**口を合成しない** で対象の元の口を残すか、**口の調整**（口角の上下・中央の折れ）で形を合わせてみてください。
- **FaceMap が選択肢に出ない**: FaceMap エディターで保存（体験版では一時保存）したか確認し、ATAA ウィンドウの **更新** を押してください。
- **元の見た目に戻したい**: 適用後なら右下の **適用を解除**（または Unity の Undo）を押してください。プレビューだけなら中央上の **調整を表示** を OFF にすると元に戻ります。
- **導入・更新後にコンパイルエラーや「バージョンが一致していません」が出る**:
  - 旧オープンβ版（`Editor/AvatarTextureAutoAdjuster.Editor.dll` が入っていた版）が残ったまま新しい `.unitypackage` を上書きした可能性があります。`Assets/Cigarless/AvatarTextureAutoAdjuster` フォルダを一度削除してから、新しい `.unitypackage` をインポートし直してください（`Assets/Cigarless/ATAA_Data` は削除しないでください）。
  - VCC / ALCOM 版でバージョン不一致が出た場合は、VCC / ALCOM のプロジェクトの管理画面から本パッケージを一度削除し、再度追加してください。

解決しないときは [お問い合わせ・不具合報告](/support/contact) からご連絡ください。
