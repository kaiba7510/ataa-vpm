# 画面に出るメッセージ

中央プレビューの上や右パネル・ステータス行に注意が出ることがあります。マウスを乗せると詳細が確認できます。

| 表示メッセージ | 意味と対処 |
|---|---|
| `顔立ちの系統が違う組み合わせです` | 通常寄りの顔とデフォルメ寄りの顔の組み合わせです。目と口の位置関係が大きく違うため、口の周りなどが崩れやすくなります（適用自体は可能です）。 |
| `口の大きさがメイク元と大きく違います` | 口が小さく描かれたデフォルメ調のアバターに、口が大きく描かれたメイク元から写す組み合わせ（比率 3 倍以上）です。唇が大きく縮んで崩れやすい場合は、プレビューで口元を拡大して確かめ、合わなければ横の **口を合成しない** を押してください（「口」タブの **合成する** で戻せます）。 |
| `パーツの周りで変形が折り返しています（調整で N か所増えました）` | 調整でパーツを大きく動かした・縮めたために、メイクが裏返って写る部分が増えています。位置・大きさを元に近づけるか、隣のパーツから少し離してみてください。 |
| `パーツの周りの歪みを自動で補正しました` | 折り返しを自動でならして補正したお知らせです。問題なければそのまま適用できます。 |
| `FaceMap に目の下の線がありません` | 下まつげが縦に潰れやすくなります。対象側が足りないときは横の **線を置く** で仮置きするか、**FaceMap エディター** で目の下の線を置いてください。 |
| `メイク元は目の開いていない素体のため、目の開いた部分は対象の元の目を残します` | メイク元の顔テクスチャに白目・瞳の領域がないため、対象の目の開いた部分は元テクスチャを残すお知らせです。 |
| `...肌色を合わせていません` | **肌色を合わせる** が ON でも肌色測定ができない状態です。透過メイクの場合は、メイク元 FaceMap に素体の顔テクスチャが記録されていないことが原因です。メイク元の素体の顔テクスチャを FaceMap エディターで開いて、メイク元 FaceMap を保存し直してください。 |
