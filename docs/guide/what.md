# ATAA とは

**Avatar Texture Auto Adjuster（ATAA）** は、あるアバター用に作られた顔のテクスチャ（メイク）を、別のアバターの顔に合わせて自動で変形・合成する Unity エディター拡張です。

![ATAA ウィンドウ全体](/img/02_ataa_whole.png){.shot}

## できること

- 目・まぶた・下まつ毛・鼻・口・頬の **位置と形の違い** に合わせて、メイクを変形します。
- メイク元と対象の **肌色をなじませて** から、顔テクスチャに合成します。
- 3D ビュー / 2D UV で **仕上がりを見ながら** パーツごとに微調整できます。
- 元のテクスチャ・マテリアルを書き換えない **非破壊** の適用です（Undo 対応）。

## しくみ

ATAA は、アバターごとに「目・鼻・口・頬がテクスチャのどこにあるか」を記録した基準データ **FaceMap** を使います。
メイクを作った側のアバター（**メイク元**）と、メイクを乗せたいアバター（**対象**）の両方の FaceMap から、パーツの位置と形の違いを求めてメイクを写します。

- FaceMap は、お手持ちのアバターから **自動生成** できます（まばたき・口のブレンドシェイプの動きから推定します）。
- 自動生成がずれるときは、**FaceMap エディター** で直せます。
- 市販アバターの FaceMap は同梱していません。

## 動作環境

- Unity 2022.3（VRChat 推奨バージョン）
- VRChat SDK（VCC / ALCOM 版は `com.vrchat.base 3.4.0` 以上が必要です）
- エディター専用です。アバターのビルド・アップロードには含まれません。

::: tip まずは体験版で
体験版はメイク適用（書き出し）以外の機能をすべて試せます。お手持ちのアバターとメイクで、仕上がりを確かめてから購入してください。→ [体験版と製品版の違い](/guide/editions)
:::
