# 体験版と製品版の違い

主な違いは、**メイクを適用（書き出し）できるか** と **作ったデータを保存できるか** です。
画面と操作手順は同じなので、購入する前に体験版で、お手持ちのアバターとメイクの仕上がりを確かめられます。

## 体験版でできること

- アバターの自動認識・FaceMap の自動生成・FaceMap エディターでの作成
- メイク元の選択とフィッティングの微調整
- 3D ビュー / 2D UV のプレビュー、シーン上のアバターへのライブプレビュー

## 製品版でできること

- 仕上がったメイクを **テクスチャとマテリアルに書き出して** アバターに適用したい → [メイクを適用する](/usage/apply)
- 作った FaceMap や調整を **保存して次回も使いたい**
- **高い解像度（最大 4096px・透かしなし）** でプレビューしたい
- 作った FaceMap を、アバターやメイク素材の商品に **同梱して配布したい** → [利用規約 3](/terms)

## 比較表

| 機能 | 体験版 | 製品版 |
|---|:-:|:-:|
| アバター自動認識・FaceMap 作成・フィッティング調整 | ✅ | ✅ |
| 3D ビュー / 2D UV プレビュー・ライブプレビュー | ✅ | ✅ |
| プレビュー解像度 | 512px<br><small>ボタンを押している間だけ 2048px（透かし入り）</small> | 最大 4096px<br><small>透かしなし</small> |
| メイク適用（テクスチャ・マテリアルの書き出し） | — | ✅<br><small>元の解像度・最大 8192px</small> |
| FaceMap・調整データの保存 | —<br><small>メモリ上だけ。Unity を閉じると消えます</small> | ✅<br><small>`Assets/Cigarless/ATAA_Data/`</small> |
| VCC / ALCOM での導入・更新 | ✅ | ✅ |

## 体験版で作ったデータについて

体験版で作った FaceMap や調整は、Unity を閉じると消えます。製品版に切り替えたら、もう一度作ってください（自動生成ならすぐに作り直せます）。

## 製品版は必要ですか？

体験版のプレビューで仕上がりに満足できたら、製品版でそのままアバターに適用できます。
プレビューの時点でうまく合わない組み合わせは、製品版でも同じ仕上がりになります。購入前に体験版で確かめてください。
