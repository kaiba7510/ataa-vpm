# 更新履歴

## 1.3.8

### 修正
- VCC（VPM）で更新したあと、FaceMap エディターの「保存して完了」・口の線のチェック・左右対称の軸／自動作成／情報の折りたたみが反応しなくなることがある問題。Unity が画面のファイル（UXML・USS）を古いまま使い続け、新しいツールの部分と合わなくなっていた。
  - 更新して最初に開いたとき、ツールの画面のファイルを 1 回だけ読み直す。
  - 画面のファイルが古いと分かったときは、その場で読み直す。
  - 配布する zip の中のファイルの日時を版ごとに変え、Unity が更新に気づくようにした（今までは全版で同じ日時だった）。
  - 画面の一部が組み立てられなくても、ほかの部分（保存・口の線など）は動くようにした。

### 変更
- FaceMap エディターの「保存して完了」を、必須の領域がそろう前でも押せるように。押すと、足りない領域をダイアログで知らせる。保存は上書き保存と同じ（まだ保存先が無ければ名前を聞いて新しく保存）。

## 1.3.6

### 変更
- ユーザーのデータ（FaceMap・調整・メイク適用で書き出したテクスチャとマテリアル・読み込んだメイク画像）の保存先を、`Assets/ATAA_Data/` からショップのフォルダの直下の `Assets/Cigarless/ATAA_Data/` に変更。ツールを入れ直すときは `Assets/Cigarless/AvatarTextureAutoAdjuster` だけを削除し、`Assets/Cigarless/ATAA_Data` は残す。
- 1.3.5 までの `Assets/ATAA_Data/` は、製品版で開いたときに自動で移す。
  - GUID を保って移すので、適用済みのアバターはそのまま使える。
  - 移したことをダイアログで知らせる（移動前・移動後の場所と移した数。「場所を表示」で Project ビューのフォルダを選べる）。
  - ファイルを 1 つずつ移す。フォルダごとは移さないので、エクスプローラーなどでフォルダを開いていても、Unity の閉じられないダイアログ（再試行 / キャンセル / 強制終了）は出ない。
  - 移動後の場所に同じ名前のファイルがあるものや移せなかったものは、上書きせずに古い側に残し、ダイアログと Console に一覧を出す。残したものがあったときは同じセッションでは再び試さず、Unity を再起動するともう一度移す。
  - 体験版は移さず、新しい場所が無ければ古い場所を読む。
- README・USAGE・操作説明書に、ツールが作るもの・出力するもの（`Generated/`・`Makeups/` を含む）がすべてこのフォルダに入ることを追記。

### 改善
- FaceMap エディターで目の線・目の下の線を動かすと、目の輪郭も一緒に動くように（スライダー・トグル・線のつまみ・目の枠の大きさの変更のどれでも）。今までは輪郭を作った後は線と切り離されていて、線を動かしても輪郭が元の場所に残り、線と輪郭がずれたまま保存されることがあった。輪郭は 2 本の線の間で比例して写し直すので、手で合わせた形（目尻の跳ね上げなど）は保たれる。目の下の線が無いときは目の線の動いた分だけずらす。目の線を消したとき・写し直すと輪郭として成り立たないときは、輪郭は直前の形のまま。目の枠の縦の大きさを変えたときも、輪郭は線と同じくテクスチャ上の高さを保つ（横は今までどおり枠と一緒に伸び縮みする）。
- メイクフィックス画面でアバターを切り替えるときの確認を、調整・メイクの濃さを変えたかどうかで出すように。メイク元を選んだだけなら出さない。変えていれば、プレビューを作り直している途中でも必ず出す（今まではプレビューの状態を条件にしていたため、タイミングで出たり出なかったりした）。適用が済んだら、それより前の変更は「変更なし」扱いにする。
- メイクフィックス画面の中央ビューの案内カードで、ボタンの無いカードの上でも 3D ビューを回転・ズームできるように。詳しい説明はカード左のアイコンのツールチップに出す。
- 右下の「次: …」ボタンとヘッダーの「あと N ステップ」で、押して移動できる項目のときだけ「›」を付けるように。移動先の無い項目（対応付けなど）は、中央のビューの案内で確かめるようツールチップで案内する。

### 修正
- FaceMap エディターで、名前・対象アバター名の欄に今と同じ値が入っただけで「未保存」になる問題。
- FaceMap エディターで、保存した直後や再コンパイルの後にも、閉じるときに未保存の確認が出ることがある問題。
- FaceMap エディターで、画面の一部の組み立て・更新でエラーが出ると残りの部分まで止まり、テクスチャを読み込んでも「顔テクスチャをドラッグ＆ドロップ」のカードが消えなくなることがある問題。画面を部分ごとに分けて動かし、エラーは Console に 1 回だけ出す。

## 1.3.2

### 修正
- 目尻と頬の外端の左右の順がメイク元と対象で逆の組み合わせ（頬が目尻より外へ出ているメイク元から、頬が目尻より内側の素体へ）で、目尻のすぐ外で変形が裏返り、合成範囲の広げ量を上げると目尻のまつげが横に伸びて見えた問題。対象の頬の外端をメイク元と同じ順にそろえて写す（しなの → Felis で、残る折り返し 290 → 2 か所）。
- メイクフィックス画面でメイクテクスチャを選んでから「この画像で手動作成」で FaceMap エディターを開いたとき、読み込んだテクスチャの上に「顔テクスチャをドラッグ＆ドロップ」のカードが重なったまま残る問題。

## 1.3.1

### 追加
- FaceMap に目の輪郭（上の縁・下の縁）を持てるように（ファイル形式 v4。古いファイルもそのまま読める）。FaceMap エディターで輪郭を表示・編集できる。
- メイク元・対象の両方に目の輪郭があるときは、目を輪郭に沿って写す（目を回り込むメイクが目の湾曲に合い、パーツの周りの折り返しが減る。しなの → Chocolat で 117 → 0）。
- メイクフィックス画面で、アバターを切り替えるときに未保存の変更を確認するダイアログ。

### 改善
- 「肌色を合わせる」の下に、合わせた比（R・G・B）か、合わせていない理由を出すように。肌の部分が透明な「重ねるだけ」のメイクで、メイク元 FaceMap の顔テクスチャがメイクそのもの（素体を入れずに作った）だと、何も出ずに肌色合わせが飛ばされ、効いているかわからなかった。
- 「パーツの周りで変形が折り返しています」の警告を、調整で増えた分だけで出すように。調整なしでも顔の組み合わせの違いで数十〜数百か所残る素体が多く、ほぼ毎回出て意味がなくなっていた。増えていないときは「歪みを自動で補正しました」のお知らせにする。

### 修正
- FaceMap エディターの別名保存で、名前の入力が重くなる問題（入力のたびでなく描画のたびにファイル名の確認が走っていた）。
- FaceMap エディターの目の線・口の線スライダーが、画面の組み立て中のイベントで値を書き換えてしまう問題。
- メイクフィックス画面から FaceMap エディターを開いたとき、顔テクスチャを選んでいなくても、前に開いていたテクスチャ（またはメイク元 FaceMap に記録されたテクスチャ）が残る問題。そのまま保存すると、違うテクスチャが FaceMap の顔テクスチャとして記録されていた。

### 内部
- コアの API の版（ApiVersion）を 4 に。`AtaaCore.ValidateEyeContour`・`AtaaCore.MeasureDistortion`・`AtaaCore.EvaluateSkinTone`（と結果の `SkinToneStatus`）を追加。

## 1.2.1

### 改善
- 変位の格子を UV の固定刻み幅（1 / 320 UV）に統一し、合成範囲の広げ・ぼかし量や「メイク元」表示の違いで変形結果が変わらないように。
- 折り返し補正の平滑化を左右対称（Red-Black Gauss-Seidel）にし、確定時・プレビュー時ともに対称な仕上がりになるように。
- TPS 係数の計算を X・Y 成分 1 回の消去に統合し、初期化を効率化。

### 修正
- 小さい口（高さ 0.01 UV 未満）で四隅の TPS 制御点が脱落し、口の上下で折り返しが発生していた問題。
- 微調整でパーツを大きく縮小（約 0.6 倍以下）したときに周囲の帯で折り返したり、離れた領域のテクスチャを引き込んだりしていた問題。
- 下まつ毛幅を 1.0 未満に縮めたときに、目尻の外側で逆走（折り返し）したり目頭より鼻側が動いたりしていた問題。
- 口の曲がり（口角の上下）を大きく掛けたときの口角外側の折り返し、口角を下げたときに鼻側へマスクが広がっていた問題、および回転との併用時のピン保護のずれ。
- 折り返しが残った場所の抑え込み（`Suppression`）が、双線形補間で保護された口の枠の内側へ染み込んで輪郭が薄まっていた問題。
- 接する固定矩形の継ぎ目すぐ外側で、`float` の桁落ちにより生の TPS 変位へ不連続に飛ぶ問題。
- 合成範囲の右端・上端ピクセルでフットプリントの差分がクランプされていた問題。

## 1.2.0
1.0.0 からの変更をまとめて記載しています（途中の版は個別に記載していません）。

### 追加
- メイクフィックス画面を UI Toolkit に刷新（右パネル上部のステップ進捗、枠付きの手順カード、設定待ちカードの点滅、「場所を表示」の結果表示）。
- プレビュー機能、メイク適用の状態表示、閉じる前・未保存変更の確認。
- 3D ビューの背景を無彩色グラデーションにし、暗 / 中 / 明 / チェッカーを切り替え可能に。
- FaceMap エディターを UI Toolkit に移行。サイズ変更ハンドルに辺の中点のつまみを追加。左右の間隔ボタンの不感帯を修正し、ドラッグの動き方をホバーで案内。
- 口の曲がり調整、口の線の真ん中から ^ / v に折る「口の折れ」。
- 「口の調整」カードを刷新（%表記、「口角の上下（弧）」「中央の折れ（v / ^）」の左右対称スライダー、個別の ↺ リセット、「自動に戻す」、説明ツールチップ）。
- 自動作成で、唇の合わせ目の曲がりから口の線を折れ線にする。縦長の目（上限 1.45）や、口の陰影連結に対応。
- 体験版: 透かし・低解像度の出力、高解像度プレビューボタン。

### 改善
- メイク適用を高速化（合成の画素ループを行ごとに並列化、読み込む元テクスチャの画素をキャッシュ）。
- 生成テクスチャの Max Size を、書き出した解像度まで上げるように。
- メイク元を大きく縮めて写すとき、1 画素の範囲を平均して拾うように。

### 修正
- アバターを切り替えた直後にメイクが一瞬ずれて映る問題。
- 口を大きく縮めて写すとき（Yumeka ← LUMINA）の口元の崩れ。
- 頬が口の上に少ししかはみ出さない素体で、口の下の写しが裏返る問題。
- OFF のパーツの位置・大きさの調整が、写し方（変形）に影響していた問題。
- 「調整をすべてリセット」と折り返しの補正に、口の曲がりが反映されていなかった問題。
- unitypackage 導入時にテクスチャの再インポートで極端に遅くなる問題（テクスチャ用 AssetPostprocessor を削除）。

### 内部
- 計算部分をコア（`AvatarTextureAutoAdjuster.Core`）に分離し、UI は入口 `AtaaCore` からのみ呼ぶ構成に。
- メイク適用の所要時間を計測する診断機能。
- 配布 DLL の難読化、FaceMap の JSON を配布パッケージに同梱しない、VPM（VCC）配布用ビルドを追加。
