# VCC / ALCOM に追加

VRChat Creator Companion（VCC）または ALCOM に、ATAA のリポジトリを追加します。
追加すると、プロジェクトの管理画面から ATAA を入れたり更新したりできるようになります。

::: tip 追加する前に
[利用規約](/terms) をお読みください。導入した時点で、利用規約に同意したものとみなします。
:::

## 体験版

1. 下のボタンを押します。

   <a class="add-button" href="vcc://vpm/addRepo?url=https%3A%2F%2Fkaiba7510.github.io%2Fataa-vpm%2Findex.json">VCC / ALCOM に追加</a>

2. VCC / ALCOM が開いたら、リポジトリ「**Cigarless**」の追加を承認します。

ボタンを押しても開かないときは、VCC / ALCOM のリポジトリ追加画面に次の URL を貼り付けてください。

- VCC: **Settings → Packages → Add Repository**
- ALCOM: **設定** 画面のパッケージ（VPM リポジトリ）の **追加**

```
https://kaiba7510.github.io/ataa-vpm/index.json
```

## 製品版

製品版のリポジトリは **購入者だけ** にお知らせしています。
BOOTH で購入してダウンロードした **「VCC_ALCOM で導入.txt」** に書かれたページを開き、そのページの **VCC / ALCOM に追加** ボタンを押してください。

::: warning 製品版の URL を人に教えないでください
購入者用の URL は、購入された方だけが使えるものです。SNS などに載せないでください。
:::

- 体験版と製品版は同時に入れられません。製品版を追加すると、体験版は自動で外れます（[製品版へのアップグレード](/guide/upgrade)）。

追加が終わったら [導入方法](/guide/install) へ進んでください。
